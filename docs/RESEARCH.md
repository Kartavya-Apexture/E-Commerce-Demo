# Research used for Aurelle

The planning stage performed the following 15 searches separately, working from setup to shopping UX, data integrity, and verification. Official technical documentation and original UX research were preferred. The implementation also inspected the documentation bundled with the installed Next.js release.

| #   | Research question                        | Source and decision                                                                                                                                                                                                            |
| --- | ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | Next.js installation, TypeScript, ESLint | [Installation](https://nextjs.org/docs/app/getting-started/installation): standard App Router starter.                                                                                                                         |
| 2   | Server versus Client Components          | [Components](https://nextjs.org/docs/app/getting-started/server-and-client-components): server reads, small interactive client components.                                                                                     |
| 3   | Current Tailwind integration             | [Next.js guide](https://tailwindcss.com/docs/installation/framework-guides/nextjs): retain the current starter’s Tailwind integration.                                                                                         |
| 4   | Responsive layouts                       | [Responsive design](https://tailwindcss.com/docs/responsive-design): mobile-first layouts.                                                                                                                                     |
| 5   | Clothing sizes and product imagery       | [Apparel research](https://baymard.com/research-articles/apparel-ecommerce-ux-research-launch): visible sizes, disabled unavailable sizes, size guide.                                                                         |
| 6   | Guest checkout                           | [Guest checkout](https://baymard.com/research-articles/make-guest-checkout-prominent): no account requirement, visible order summary.                                                                                          |
| 7   | Node’s built-in SQLite                   | [Node SQLite](https://nodejs.org/api/sqlite.html): evaluated; not selected for this installed runtime.                                                                                                                         |
| 8   | SQLite driver and transactions           | [better-sqlite3 API](https://github.com/WiseLibs/better-sqlite3/blob/master/docs/api.md): prepared statements and immediate transactions. Version 12.11.1 is pinned because 13.0.3 crashed on this Windows/Node 22.13 runtime. |
| 9   | Admin authentication                     | [Authentication](https://nextjs.org/docs/app/guides/authentication): opaque sessions, HttpOnly cookies, authorization in each protected operation.                                                                             |
| 10  | Forms and validation                     | [Forms](https://nextjs.org/docs/app/guides/forms): server validation with Zod and action pending/error states.                                                                                                                 |
| 11  | Strict TypeScript                        | [noImplicitAny](https://www.typescriptlang.org/tsconfig/noImplicitAny.html), [no-explicit-any](https://typescript-eslint.io/rules/no-explicit-any/): strict types; unknown external inputs validated before use.               |
| 12  | Product image optimisation               | [Image](https://nextjs.org/docs/app/api-reference/components/image): local images, meaningful alt text, responsive image sizes.                                                                                                |
| 13  | Accessible dialogs                       | [Native dialogs](https://www.w3.org/WAI/WCAG22/Techniques/html/H102): focus trapping, Escape dismissal, focus return.                                                                                                          |
| 14  | Production browser tests                 | [Playwright](https://nextjs.org/docs/app/guides/testing/playwright): exercise the built production app and use a separate test database.                                                                                       |
| 15  | Data updates                             | [revalidatePath](https://nextjs.org/docs/app/api-reference/functions/revalidatePath): refresh affected routes after mutations; refresh another browser manually.                                                               |

Additional implementation research: [Unsplash licence](https://unsplash.com/license) for the supplied local sample photographs. See IMAGE-CREDITS.md. This demo is local, uses sample products and policies, and does not process real payments.
